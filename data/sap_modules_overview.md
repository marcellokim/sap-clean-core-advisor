# SAP ERP 모듈 개요 및 기술 부채 특성

## SAP ERP 핵심 모듈

### FI – Financial Accounting (재무 회계)
- **기능:** 총계정원장, 채권/채무 관리, 자산 관리, 결산
- **S/4HANA 변화:** Universal Journal 도입으로 원장 통합
- **커스텀 빈도:** 높음 – 국가별 법규, 세금 계산, 결산 리포트
- **기술 부채 가중치:** 1.5
- **Clean Core 전환 시 주요 과제:** 법정 보고서 커스텀, 전표 검증 로직, 결산 프로그램

### CO – Controlling (관리 회계)
- **기능:** 원가 센터, 이익 센터, 내부 주문, 제품 원가
- **S/4HANA 변화:** FI/CO 통합 강화, 실시간 수익성 분석
- **커스텀 빈도:** 중간 – 배부 로직, 원가 계산 변형
- **기술 부채 가중치:** 1.2
- **Clean Core 전환 시 주요 과제:** 배부 규칙 커스텀, CO-PA 보고서

### MM – Materials Management (자재 관리)
- **기능:** 구매, 재고 관리, 자재 평가, 송장 검증
- **S/4HANA 변화:** 간소화된 자재 문서, 중앙 구매
- **커스텀 빈도:** 높음 – 구매 프로세스, 승인 워크플로우, MRP
- **기술 부채 가중치:** 1.3
- **Clean Core 전환 시 주요 과제:** 구매 요청 승인 로직, 재고 평가 커스텀

### SD – Sales & Distribution (영업/유통)
- **기능:** 수주, 출하, 청구, 가격 결정
- **S/4HANA 변화:** 신용 관리 개선, 가격 결정 간소화
- **커스텀 빈도:** 매우 높음 – 업종별 가격 조건, 출력물, 인터페이스
- **기술 부채 가중치:** 1.4
- **Clean Core 전환 시 주요 과제:** 가격 조건 테이블 커스텀, 출력물(Invoice) 폼

### PP – Production Planning (생산 계획)
- **기능:** 생산 계획, 작업 지시, 공정 관리, MRP
- **S/4HANA 변화:** 내장형 PP/DS, Demand-Driven MRP
- **커스텀 빈도:** 중간 – MRP 로직, 생산 일정 계획
- **기술 부채 가중치:** 1.1
- **Clean Core 전환 시 주요 과제:** MRP 커스텀 로직, 공정 자동화 인터페이스

### HR/HCM – Human Capital Management (인사 관리)
- **기능:** 인사 마스터, 급여, 근태, 채용
- **S/4HANA 변화:** SuccessFactors로 전환 권고
- **커스텀 빈도:** 최고 – 국가별 급여 체계, 법정 신고, 근태 규칙
- **기술 부채 가중치:** 1.6
- **Clean Core 전환 시 주요 과제:** 급여 계산 커스텀, 4대 보험 연동, 법정 서식

### PM – Plant Maintenance (설비 보전)
- **기능:** 설비 관리, 예방 보전, 작업 지시
- **S/4HANA 변화:** SAP Asset Performance Management 통합
- **커스텀 빈도:** 낮음-중간
- **기술 부채 가중치:** 0.9
- **Clean Core 전환 시 주요 과제:** IoT 연동 인터페이스, 보전 계획 커스텀

### QM – Quality Management (품질 관리)
- **기능:** 품질 검사, 불량 관리, 인증서 관리
- **S/4HANA 변화:** 디지털 품질 관리 도입
- **커스텀 빈도:** 낮음
- **기술 부채 가중치:** 0.8
- **Clean Core 전환 시 주요 과제:** 검사 로트 커스텀, 품질 인증서 출력

### WM/EWM – Warehouse Management (창고 관리)
- **기능:** 입출고 관리, 재고 위치 관리, 피킹
- **S/4HANA 변화:** EWM(Extended Warehouse Management) 내장형으로 통합
- **커스텀 빈도:** 중간
- **기술 부채 가중치:** 1.0
- **Clean Core 전환 시 주요 과제:** WM→EWM 전환, RF 장비 인터페이스

### PS – Project System (프로젝트 시스템)
- **기능:** 프로젝트 계획, 예산 관리, 진행 관리
- **S/4HANA 변화:** 프로젝트 관리 UX 개선
- **커스텀 빈도:** 낮음-중간
- **기술 부채 가중치:** 1.0
- **Clean Core 전환 시 주요 과제:** 진행률 산정 커스텀, 수주 연동

## 모듈 간 통합 복잡도

SAP ERP의 핵심 가치는 모듈 간 통합이다. 전환 시 이 통합 관계를 반드시 고려해야 한다.

### 높은 통합 복잡도 조합
- **SD ↔ FI:** 매출 인식, 청구 → 회계 전기
- **MM ↔ FI:** 구매 → 자재 평가 → 회계 전기
- **PP ↔ MM:** 생산 → 자재 소요 → 구매
- **CO ↔ FI:** 원가 배부 → 수익성 분석

### 전환 우선순위 권고
1. **1순위:** FI/CO (재무의 기반이 되므로 먼저 안정화)
2. **2순위:** MM/SD (핵심 업무 프로세스)
3. **3순위:** PP/PM/QM (생산/설비)
4. **4순위:** HR (별도 프로젝트 권고 – SuccessFactors)
