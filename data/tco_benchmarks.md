# SAP ERP TCO 벤치마크 및 비용 분석 가이드

## TCO(Total Cost of Ownership) 정의

TCO는 시스템의 도입부터 운영, 유지보수, 최종 폐기까지 전체 수명주기에 걸쳐 발생하는 모든 비용의 합계이다. SAP ERP의 TCO를 정확히 이해하는 것은 RISE with SAP 전환 의사결정의 핵심이다.

## On-Premise SAP ERP의 TCO 구성

### 1. 인프라 비용 (전체 TCO의 25-30%)
- **서버 하드웨어:** 초기 구매 및 3-5년 주기 교체
- **스토리지:** DB 증가에 따른 지속적 확장
- **네트워크:** 데이터센터 네트워크 인프라
- **전력/냉각:** 데이터센터 운영 비용
- **DR(재해복구):** 이중화 인프라 비용
- **벤치마크:** 사용자 1인당 연간 약 30-50만원

### 2. 소프트웨어 라이선스 (전체 TCO의 15-20%)
- **SAP ERP 라이선스:** Named User 또는 Package 기반
- **DB 라이선스:** Oracle, SQL Server 등
- **OS 라이선스:** Windows Server, Linux 등
- **보안 소프트웨어:** 방화벽, 백신, 모니터링
- **벤치마크:** 사용자 1인당 연간 약 80-120만원

### 3. 인건비 (전체 TCO의 30-35%)
- **Basis 관리자:** 시스템 운영, 패치, 모니터링
- **ABAP 개발자:** 커스텀 코드 유지보수
- **기능 컨설턴트:** 비즈니스 프로세스 지원
- **DBA:** 데이터베이스 관리
- **벤치마크:** 전담 인력 3-10명 (기업 규모에 따라)

### 4. 커스텀 코드 유지보수 (전체 TCO의 15-25%)
- **버그 수정:** 커스텀 코드의 결함 처리
- **업그레이드 영향 분석:** EHP/패치 적용 시 커스텀 코드 호환성 테스트
- **기능 개선:** 비즈니스 요구사항 변경에 따른 수정
- **문서화:** 기술 문서 및 사용자 매뉴얼 유지
- **벤치마크:** 커스텀 프로그램 1개당 연간 약 50만원 (평균)

## 커스텀 코드 비중별 TCO 영향

| 커스텀 비중 | TCO 증가율 | 업그레이드 난이도 | 운영 리스크 |
|------------|-----------|-----------------|-----------|
| 0-10% | 기준(Base) | 쉬움 | 낮음 |
| 10-30% | +15-25% | 보통 | 보통 |
| 30-50% | +30-50% | 어려움 | 높음 |
| 50-70% | +60-100% | 매우 어려움 | 매우 높음 |
| 70%+ | +100%+ | 사실상 불가 | 극심 |

## RISE with SAP 전환 후 TCO 변화

### 절감 영역

#### 인프라 비용: 30-40% 절감
- 데이터센터 운영 비용 제거
- 하드웨어 구매/교체 주기 불필요
- DR/백업 자동화
- 클라우드 탄력적 확장/축소

#### 운영 인건비: 20-30% 절감
- Basis 관리 업무 대폭 축소 (SAP 관리형 서비스)
- 패치/업그레이드 자동화
- 모니터링 자동화
- DBA 업무 감소 (HANA Cloud 관리형)

#### 커스텀 코드 유지: 40-60% 절감 (Clean Core 전략 적용 시)
- 불필요 코드 폐기(Retire): 30-40% 제거
- 표준 대체(Replace): 20-30% 전환
- 나머지만 유지/리팩토링

#### 업그레이드 비용: 70% 이상 절감
- 연간 2회 자동 업데이트 (커스텀 코드 영향 최소화)
- 업그레이드 프로젝트 불필요

### 증가 영역
- **구독 비용:** 기존 라이선스 대비 증가할 수 있음
- **BTP 사용료:** 확장 기능에 따른 추가 비용
- **전환 프로젝트 비용:** 일회성 마이그레이션 비용

## 투자 회수 기간 (Payback Period)

| 기업 규모 | 초기 투자 | 연간 절감 | 회수 기간 |
|-----------|-----------|-----------|-----------|
| 중소기업 | 3-5억원 | 1-2억원 | 2-3년 |
| 중견기업 | 10-30억원 | 5-10억원 | 2-4년 |
| 대기업 | 50-200억원 | 20-50억원 | 3-5년 |

## 숨겨진 비용 (Hidden Costs) 주의사항

1. **변경 관리(Change Management):** 사용자 교육, 프로세스 재설계 비용
2. **데이터 마이그레이션:** 데이터 정리, 변환, 검증 비용
3. **네트워크 업그레이드:** 클라우드 접속을 위한 네트워크 대역폭 증설
4. **보안 재설계:** 클라우드 보안 아키텍처 재설계
5. **병행 운영 기간:** 전환 기간 중 두 시스템 동시 운영 비용
