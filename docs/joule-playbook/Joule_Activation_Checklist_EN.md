# Joule Activation Checklist (EN)

## 1. Prerequisites
- [ ] Verify target system version/patch
- [ ] Confirm required service enablement
- [ ] Validate tenant/subaccount readiness

## 2. Security & Authorization
- [ ] Validate role/authorization mapping
- [ ] Prepare isolated test users
- [ ] Confirm audit/logging policy

## 3. Connectivity & Configuration
- [ ] Check endpoint/integration setup
- [ ] Run initial response quality check
- [ ] Confirm fallback path on failure

## 4. Validation
- [ ] Execute sample prompt set
- [ ] Verify evidence/source traceability
- [ ] Validate error code and retry policy

## 5. Go-Live
- [ ] Handover to operations
- [ ] Share FAQ/troubleshooting guide
- [ ] Set weekly monitoring cadence
