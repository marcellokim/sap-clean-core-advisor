# Joule Activation Checklist (KO)

## 1. 사전 조건
- [ ] 대상 시스템 버전/패치 확인
- [ ] 관련 서비스 활성화 상태 확인
- [ ] 테넌트/서브어카운트 준비 여부 확인

## 2. 권한/보안
- [ ] 역할/권한 매핑 검토
- [ ] 테스트 사용자 분리
- [ ] 감사 로그 정책 확인

## 3. 연결/설정
- [ ] 엔드포인트/연동 설정 확인
- [ ] 초기 응답 품질 확인
- [ ] 실패 시 fallback 경로 확인

## 4. 검증
- [ ] 샘플 프롬프트 세트 실행
- [ ] 응답 근거/출처 확인
- [ ] 오류코드 및 재시도 정책 확인

## 5. Go-Live
- [ ] 운영자 인수인계
- [ ] FAQ/트러블슈팅 공유
- [ ] 주간 모니터링 일정 설정
